Menu variations that price correctly

Configure free or paid menu-specific choices, require selection before adding configured products, and preserve an immutable order snapshot.

Requested behavior

What changes

  • Less sugar can be selected at no charge.
  • 1 extra shot adds its configured surcharge.
  • Configured menu cards open a customization modal before cart insertion.
  • Menus without variations keep one-tap ordering.

Minimal model

MenuVersion.variations? holds groups and options. Each group is required or optional and single-select. Each option has a non-negative priceDelta.

CartLine snapshots base price, selected group/option IDs and labels, deltas, and the final unit price. Legacy records remain valid because new fields are optional.

Ordered implementation

1 · Isolate and baseline

Create the feature branch. Run baseline tests, typecheck, and build; stop on failure.

2 · Domain first

Add variation types, validation, cart-line snapshot helper, selection-aware merging, and focused reducer tests.

3 · Admin configuration

Add native fieldsets for groups/options to the existing menu modal. Validate, version, persist, and summarize. Standard items only.

4 · Cashier modal

Use labelled radio groups, optional None choices, quantity controls, live price, required-selection validation, and accurate cart snapshots. Preserve long press, keyboard details, sold-out behavior, and direct add for plain items.

5 · Downstream snapshots

Seed Cappuccino examples and prove held/resumed/completed orders, Kitchen, history, coupon, and tax behavior.

6 · Verify and deliver

Full test/lint/typecheck/build, authenticated public E2E on desktop and mobile, console/network checks, exact diff review, commit, and push.

Acceptance checks

  • A configured item is not added until valid choices are submitted.
  • Free choices add zero; extra shot adds Rp7.000 per unit.
  • Different selections stay separate; identical selections may merge.
  • Quantity, discounts, tax, hold/resume, completed history, and Kitchen use snapshot values.
  • Reload and later menu edits cannot rewrite historical order labels or prices.
  • Modal is keyboard accessible, Escape-safe, focus-trapped, and has no 390px overflow.

Deliberate cuts

No multi-select, selection counts, option stock, nested choices, reusable cross-menu modifier library, ingredient deduction, backend, or new dependency. Add only when a concrete workflow needs it.

Implementation gate

This is a review plan only. No application files, deployment, commits, or production data have changed. Explicit implementation approval is required.
