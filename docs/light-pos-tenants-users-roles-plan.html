Problems captured

Missing Tenants workspace

Superadmin needs add, edit, disable and enable operations.

Inline forms

Edit user and Create/Edit access profile currently appear below page content.

Wrong concept language

Access Profiles should be presented as Roles.

Weak data surfaces

Users and roles need proper tables with quick search, filtering and sorting.

Current evidence

  • server/app.mjs:113–115 already has secured tenant list/create/update endpoints and an active flag.
  • AdminUsersAccessPage.tsx:22–25 uses status rows/cards and inline forms.
  • molecules.tsx:6–7 already contains the accessible focus-trapping Modal and FormActions.
  • Existing APIs already enforce user, role, menu-scope and tenant boundaries.

Confirmed defaults

  • Rename only user-facing language to Roles; retain API, schema and capability identifiers.
  • Reuse existing endpoints and modal components; add no dependency.
  • Tenant ID is immutable after creation. Disable is reversible; no delete.
  • Use client-side controls for current tenant-sized datasets.
  • Tenants route is available only to global superadmin.

Implementation sequence

  1. Frontend tests first: route visibility, terminology, dialogs, search/filter/sort.
  2. Tenants page: new page, explicit global-superadmin guard, existing APIs, modal forms.
  3. Users & roles: semantic responsive tables, native controls, modal forms, preserved permission/menu-scope logic.
  4. Security verification: backend authorization and disabled-tenant behavior.
  5. Delivery: changelog/docs, typecheck, lint, tests, build, live restart/deploy, public E2E, commit and push.

Acceptance criteria

  • Only global superadmin can access Tenants.
  • Tenant lifecycle persists after reload; disabled tenants remain manageable but operationally inaccessible.
  • All touched UI says Roles, not Access Profiles.
  • User and role forms open as accessible dialogs.
  • All three tables support the specified search, filters and reversible sorting.
  • Existing permissions, protected roles, assignments, menu scope, CSRF and tenant boundaries remain intact.
  • All local checks and public E2E pass; changelog is updated.
